Hermes — Nataliya / Privacy

Privacy Policy

Effective October 21, 2026. This policy describes the owner's personal Google Workspace integration with Hermes Agent. It is not a public multi-user service.

Operator and purpose

The operator is Nataliya, owner of NNikolskaya. Google account data is used for owner-requested personal assistance, including email triage, job-alert discovery, calendar organization, and document and spreadsheet workflows. This is an independent personal integration, not an official Google or Nous Research application.

Data accessed

Within the permissions granted and the tasks requested, the agent may access Gmail message content, metadata, attachments and labels; calendar events; Drive file metadata and content; Google Docs and Sheets content; and contact information. OAuth access and refresh tokens allow the local installation to authenticate to Google.

Write permissions can allow sending or modifying email, managing calendar events and files, and editing documents and spreadsheets. The owner controls which actions are requested and the confirmation requirements applied to them.

Use and disclosure

Google data is used to carry out the owner's requested tasks. It is not sold or used for advertising. This integration does not use Google account data to develop or train generalized AI or machine-learning models.

Hermes Agent may send relevant task content to the AI model provider configured by the owner for inference. Depending on the task, this may include email or document excerpts and agent context. The owner must select provider settings and terms compatible with the sensitivity of the data and applicable Google data-use requirements. Provider-side retention and processing depend on that configuration; this policy does not promise that all processing stays on the local machine or that every provider offers zero retention.

Information may also be sent to tools, storage services or messaging destinations selected by the owner, such as a job tracker or a report channel. Reports should include only information appropriate for that destination. No unrelated third-party access is offered by this integration.

Storage, security and retention

OAuth credentials are stored in the owner's local Hermes profile. Credential file permissions are restricted to the owner. Google API communication uses HTTPS. The static public website and its repository contain no Google credentials or account content.

Task content may persist in local agent sessions, logs, reports, backups, or owner-selected destinations until the owner deletes it. This installation does not promise an automatic fixed deletion interval. AI providers and selected services have their own retention controls and terms. The owner is responsible for configuring those controls and protecting the local machine and backups.

Revoke access or delete data

The owner can revoke this application's access in Google Account connections. Local authentication can also be revoked through the Google Workspace setup tool. Revocation prevents future authorized access but does not automatically erase previously generated reports, local history, backups or copies in selected services. Those must be deleted separately using the relevant storage or service controls.

Public website and contact

This static GitHub Pages site has no application login, analytics scripts, cookies set by this application, or account-data submission form. GitHub may process visitor request information as the hosting provider under its own privacy terms.

For a non-sensitive question, contact the operator through this repository's issues. Issues are public: never post credentials, authorization codes, email content, or personal documents there.
